# 月の手帖 — タロットの学び

ウェイト版のタロットを、解説と三択で学ぶスマートフォン向けWebアプリです。

## 機能

- 78枚のカード図鑑、正位置・逆位置の解説
- 1回10問の三択と、10項目ずつ読む学習モード
- ジャンル別のランダム学習、カード番号順の学習
- 1枚引き・3枚引き・ケルト十字の置き方
- 復習リストと最近50回の学習履歴
- ログイン不要・ブラウザ内保存・JSONのダウンロード／インポート
- スマートフォン向け下部ナビゲーション

## 構成

HTML・CSS・JavaScriptのみの静的サイトです。外部API・データベース・ビルドは不要です。

- `docs/index.html`: 画面の入口
- `docs/app.js`: UI・学習・記録
- `docs/data.js`: カード・設問・配置データ
- `docs/backup.js`: バックアップの形式検証
- `docs/style.css`: レスポンシブデザイン
- `docs/assets/cards/`: 78枚のカード画像と取得元一覧
- `docs/manifest.webmanifest`: ホーム画面に追加したときのアプリ名・アイコン・配色
- `docs/sw.js`: 一度開いたページをオフラインでも表示するService Worker
- `docs/icons/`: ホーム画面用アイコン（「月」のカードの月の顔と光の筋を切り出したもの）
- `icons.py`: `docs/icons/` の生成元（Pillowが必要。サイトの起動には不要）
- `tests/backup.test.cjs`: バックアップのテスト

## ローカル実行

```sh
python3 -m http.server 8000 --directory docs
```

テストはNode.jsの標準機能だけで実行できます。

```sh
node --test tests/backup.test.cjs
```

## GitHub Pages

リポジトリの **Settings → Pages** で Source に **Deploy from a branch**、Branch に **main**、Folder に **/docs** を指定します。

`docs/.nojekyll` により静的ファイルをそのまま配信します。以後は `main` の `docs/` を更新すると公開内容も更新されます。

## ホーム画面への追加

AndroidのChromeで公開サイトを開き、メニューの「ホーム画面に追加」または「アプリをインストール」を選ぶと、アプリとして起動できます。iPhoneのSafariでは共有メニューの「ホーム画面に追加」を使います。

一度開いたページ・カード画像は端末に保存され、電波のない場所でも表示されます。まだ開いていないカード画像は表示されません。
`docs/sw.js` の `CACHE` の値を変えると、各端末の保存済みファイルが入れ替わります。HTML・CSS・JSはつながる場所では毎回公開サイトから読むため、文章や画面の変更では値を変える必要はありません。画像を同じファイル名で差し替えたときだけ変更してください。

## 学習記録と移行

記録は利用中のブラウザの `localStorage`（キー `tsuki-study-v1`）に保存されます。サーバーへの回答データ送信や自動同期は行いません。

**公開URLが変わる場合は、旧サイトの「記録」でJSONをダウンロードし、新サイトの「記録」でインポートしてください。** 同じ端末でもドメインが異なると保存領域は別になります。インポートは現在の記録を置き換えます。途中の学習セットはバックアップに含まれません。

ブラウザデータの削除やプライベートブラウズ終了で記録が消える場合があるため、定期的にバックアップしてください。

## カード画像と教材

画像の作者は Pamela Colman Smith、デッキは Rider–Waite–Smith（1909年）です。配布元がパブリックドメインと明記する [sixseeds/tarot-api](https://github.com/sixseeds/tarot-api) の画像セットを利用し、縮小・WebP変換しています。各画像の取得元と加工内容は [sources.json](docs/assets/cards/sources.json) に記載しています。画像の再生成・描き換えは行っていません。

解説は初学者向けの代表的な読み方です。唯一の正解や将来の保証を示すものではありません。参考文献はアプリ内「この教材について」に掲載しています。
